# How to contribute

## Preparation

The all you need are:

* [Google Earth Pro](https://www.google.com/intl/zh-TW/earth/about/versions/#download-pro)

* [Visual Studio Code or your favorite text editor](https://code.visualstudio.com)

* [GitKraken or any git clients](https://www.gitkraken.com)

* [Euroscope designer tool](https://fsmine.dhis.org/euroscope/design)

* [an GitHub account](https://github.com)

* [Charts(can get from AIS or Navigraph)](https://aisjapan.mlit.go.jp)
